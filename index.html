how I build

From idea to working software.

Each project starts with a real workflow, then grows through small decisions I can test, explain, and improve.

  1. 01

    Define the problem

    Translate a familiar need, like tracking inventory or support requests, into clear users, inputs, and outcomes.

  2. 02

    Model the logic

    Plan the data, menus, routes, and validation before connecting the pieces in Python or Flask.

  3. 03

    Build and test

    Start with a usable core, check edge cases, and refine the interface so the workflow feels clear.

  4. 04

    Review and explain

    Use feedback and code review to improve the project, then document what changed and what I learned.
